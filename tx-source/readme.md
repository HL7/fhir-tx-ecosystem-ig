# Introduction
This folder contains testing material for large external code systems;
these are the sources for the test cases on LOINC, SNOMED CT etc.

What follows is notes about how to prepare the subsets

## SNOMED CT
The data under the `snomed` folder is a small test subontology with effective time 20250909, extracted from the International August 2025 release. 

The snapshot must be imported with a specific URI `http://snomed.info/xsct/31000003106/version/20250909`.
- `xsct` means unpublished release
- `31000003106` is the Test subontology module.

The `snomed-expand-count-all` test can be used to verify the loaded concept count.

### Test extension content
Everything in the subset is International Edition content (modules 900000000000207008 and 900000000000012004) except the module concept itself. The files tagged `TEST1000003` alongside the `INT` ones add four extension concepts in module 31000003106 (namespace 1000003), so that national edition → International translation can be tested. Each is defined only from International concepts that are in the subset:

- `1000011000003104 |Structure of kidney adjacent to liver|` - fully defined, one ungrouped attribute (Laterality = Right)
- `1000071000003108 |Acute toxic hepatitis caused by liver pate|` - fully defined, role-grouped, no International equivalent
- `1000161000003101 |Liver biopsy using the ultrasound thingy|` - fully defined, equivalent to `438300009 |Biopsy of liver using ultrasound guidance|`
- `1000261000003107 |Feeling liverish|` - primitive, IS A `300338006 |Liver problem|` only
- `1000311000003101 |Feeling vaguely unwell about the liver|` - primitive, directly under `404684003 |Clinical finding|` (no useful International ancestor)
- `1000351000003102 |Dropsy of the liver|` - inactive, no relationships and no historical association
- `1000381000003107 |Hepatic revenge syndrome|` - inactive, REPLACED BY `4896000 |Acute toxic hepatitis|` (the SAME AS refset concept is not in the subset, so REPLACED BY is used)

They are generated by `utilities/make-sct-test-extension.js` in the FHIRsmith repository (deterministic ids, Verhoeff check digits), which should be re-run rather than editing the files by hand. With them (and the LOINC Extension content below) the edition has 2280 concepts (three of them inactive).

### LOINC Extension content
The files tagged `LO1010000` add a small subset of the SNOMED CT LOINC Extension (the LOINC ontology, module `11010000107`, namespace 1010000), taken from the 2026-10-21 release, so that the agreed LOINC Extension functionality can be tested. Apart from 2067-7, every LOINC code is also in the LOINC test subset (`loinc/`), so translations can be checked in both directions:

- `$lookup` on a SNOMED CT concept returns its LOINC code as the `loinc` property (a Coding), both when asked for and when no properties are asked for
- `$translate` in both directions using the implicit concept map `[edition]/version/[date]?fhir_cm=11010000107` (the LOINC Extension module), following the pattern of the edition maps
- `$expand` with the filter `mapped:30051010000102` `exists` `true`/`false` for concepts that do / don't have a LOINC code (the `mapped:` prefix keeps it apart from the SNOMED CT attribute filters; pending review by the SNOMED committee)

The concept, description, language refset and identifier (`sct2_Identifier`, scheme `30051010000102 |LOINC code identifier|`) rows are as published, except that every row is given the edition's effective time (20250909). The LOINC ontology's defining relationships and OWL axioms are *not* included, since they reference several hundred concepts that are not in the subset. ### SNOMED Subset Generation Process
_Generating the subontology is not necessary because the output files are already available in the `snomed` folder._

If you want to recreate the subset, first create the OWL Ontology file using the [SNOMED OWL Toolkit](https://github.com/IHTSDO/snomed-owl-toolkit).
```
java -jar --add-opens java.base/java.lang=ALL-UNNAMED snomed-owl-toolkit-executable.jar -rf2-to-owl \ 
 -rf2-snapshot-archives SnomedCT_InternationalRF2_PRODUCTION_20250801T120000Z.zip -version 20250801
```
Then take `snomed-subset.txt` from this repository and run the [SNOMED Subontology Extraction](https://github.com/IHTSDO/snomed-subontology-extraction) tool to create the subontology with effective time 20250909:
```
java -jar --add-opens java.base/java.lang=ALL-UNNAMED snomed-subontology-extraction-executable.jar \
 -source-ontology ontology-20250801.owl -input-subset snomed-subset.txt -output-rf2 -rf2-snapshot-archive SnomedCT_InternationalRF2_PRODUCTION_20250801T120000Z.zip \
 -include-inactive -effective-time 20250909
```

## LOINC CT

The subset is prepared by the code at https://github.com/HealthIntersections/nodeserver,
and running

```
npm install
tx-import loinc-subset
```

You then have to provide a reference to a downloaded LOINC source, 
and a list of LOINC codes to import, which is found in
loinc-subset.txt in this folder
